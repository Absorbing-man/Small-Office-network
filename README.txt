PROJECT: Small Office Network

Purpose:
Created a small office network using Cisco Packet Tracer.

Devices:
- 1 Router
- 1 Switch
- 3 PCs

Configuration:
- IPv4 addressing
- DHCP
- DHCP Exclusion
- Default gateway
- Network connectivity
- Viewing the current IP to MAC by using DHCP Binding

What I learned:
- How IP addresses work
- How DHCP Exclusion works
- How DHCP assigns IP addresses
- How devices communicate through a switch/router
- How to troubleshoot connectivity using Simple PDU
- How to view the DHCP Binding
